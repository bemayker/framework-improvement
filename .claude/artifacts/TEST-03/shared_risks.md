## Existing files this feature will modify
- backend/app/main.py: registers the notes router, adds CORS middleware and the lifespan schema init
- backend/app/core/config.py: adds the `cors_origins` setting
- backend/pyproject.toml: adds the psycopg dependency
- backend/uv.lock: regenerated by the dependency change
- backend/tests/conftest.py: adds real-database fixtures next to the existing client fixture
- frontend/src/components/LandingPage.tsx: renders the note form and list
- frontend/src/components/LandingPage.test.tsx: covers the new composition
- frontend/tsconfig.json: adds `vite/client` to the types array
- docs/DEVELOPMENT.md: documents the database requirement for the backend test suite

## Potential conflicts with other independent features
- backend/app/main.py may also be modified by TEST-02 (independent, could run concurrently): `feature_map.md` flags exactly this pair — both register a router on the FastAPI app entry. Serialize rather than run concurrently.
- frontend/src/components/LandingPage.tsx may also be modified by TEST-04 (independent, could run concurrently): flagged in `feature_map.md`. TEST-04 appears already merged on main (`AppFooter` is present), so in practice this risk is behind us, but the flag stands as recorded and any TEST-04 revision would collide here.
- backend/tests/conftest.py and backend/app/core/config.py may also be modified by TEST-02: existing code comments in both `main.py` and `conftest.py` earmark TEST-02 ("health endpoint") as the feature that introduces DB connectivity and DB test fixtures; TEST-03 now lands that layer first. If TEST-02 is planned or built concurrently, it must be serialized after TEST-03 and re-planned against the DB layer this feature introduces (its health check can reuse `core/db.py` instead of creating a parallel one).
- backend/pyproject.toml and backend/uv.lock may also be modified by TEST-02 for the same reason (a DB-backed health check would want the same driver); a concurrent dependency edit to these two files is a guaranteed merge conflict on the lockfile.
